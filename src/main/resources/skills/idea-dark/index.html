科技暗色：IDE 工作台

// 约束：无 div · 无 JS · 无 class · 全部内联

高亮 关键标识符，用低饱和蓝区分层级。

侧栏 Project · 编辑区 · 状态栏，三段固定心智。

// structure

结构即导航

文件树不用装饰，选中态一条左线就够。

// typing

等宽优先

正文可等宽；标题可用系统无衬线降噪。

// accent

语义色克制

蓝选中、绿通过、黄警告，不铺满。

Inspect

theme .. Darcula-like

surface . #1e1f22 / #2b2d30

accent .. #3574f0

rules .. inline-only

Editor 骨架约定

  • 顶栏窗口壳 + 左 Project 树 + 右编辑区
  • 卡片/面板统一 6px 圆角、1px 描边
  • 状态读数放底部或 Inspect 区，等宽键值对

// conclusion

IDE 感来自密度与分区，不来自闪烁

暗色科技风：分区清楚、语法色当语义、可复制路径。
