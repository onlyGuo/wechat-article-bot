幽默斗图
奶黄底、粗黑边、硬阴影与分镜吐槽组成的幽默斗图风，适合轻松解释风险、误区和反转。

## 写作与结构
先自嘲，再揭示反差，最后给出自救。语气机灵、短促、有梗，但事实必须准确；嘲讽现象和选择，不羞辱具体个人。用“当时 → 背后 → 翻车 → 对峙/自救 → 纪律 → 结论”的分镜推进，文字像弹幕补刀，不能取代解释。

## 版式与样式
- 语义 HTML、逐元素内联 style；禁止 div、class、style 标签与脚本。
- body 奶黄 #fffbe8、正文 #2b2118；main 最大 36rem。主标题橙 #ff9f1c、4px 黑边、粗圆角和 5–6px 硬阴影。
- 场景卡使用白底、4px #2b2118、20–24px 圆角，分别配 #ffd166、#9bdeac、#ffb4a2 等硬阴影；强调块用 #ffe8a3/#d8f3dc/#ffcad4。
- 标题字重 800–900，正文 0.92–1rem；每卡一条场景标签、一句梗和一段解释。不要一页塞满表情符号。
- 结尾用橙红渐变重卡，但落点应是可执行判断。

## 笑点与分镜细则
- 每格必须同时有“角色正在做什么”和“事实上的反差”，笑点之后紧跟准确解释；不能只有夸张表情，没有因果。
- 固定主要角色与对手的外形标识，SCENE 标签和颜色顺序前后一致。攻击对象是做法、误区或机制，不影射真实个人的外貌和身份。

## 配图与图片生成
- 统一为贴纸表情包、四格漫画或网络漫画分镜：粗黑外轮廓、2–3 头身、平涂、高饱和但非荧光、白色贴纸边，用汗滴、惊叹线和碎裂块表达反应。
- 每张提示词必须包含角色身份与外形、具体场景、正在做的动作、拟人化问题如何制造冲突、主角是否察觉、关键道具和夸张反应；禁止只写“震惊表情包”。
- 图片序列按“自信操作 → 背后冲突 → 翻车发现 → 主动修正”展开，角色服装、配色、道具和线条一致；可改变景别但不能换画风。
- 封面选择冲突最清楚的一帧并预留标题区域；正文图用中景讲关系、特写讲关键道具。若需要对白，使用 HTML 气泡在图外呈现。
- 禁止画中文字、口号、logo、二维码、水印、真实人像丑化、品牌诽谤和只有一句“别用了”的海报。
- 生成后只使用素材工具返回的 `publicUrl`，不得外链、base64、临时 URL 或占位图；alt 描述角色、动作、冲突和结果。

## 交付校验
- 仅看场景卡和图片也能复述“当时—背后—翻车—自救”，仅看正文也能得到准确事实；笑点不过量，最终行动明确可执行。

好笑负责记忆，证据负责可信。
