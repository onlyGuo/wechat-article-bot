诱惑紫色
浅紫白底、丝绒渐变和衬线低语组成的优雅紫色风，适合品牌、审美、情绪与夜读内容。

## 写作与结构
语气优雅、含蓄、靠近感强；短句、留白和斜体判断多于加粗。可以保留一点未说尽的余味，但事实和主张必须明确。结构参考“丝带头卡 → 序言 → 三层丝绒论证 → 礼仪清单 → 双线收束”。

## 版式与样式
- 语义 HTML、逐元素内联 style；禁止 div、class、style 标签与脚本。
- body 浅紫白 #fbf7fc，卡片 #fff，正文 #3a2a45/#5c4068，主紫 #6b2d8b/#4a1f5c，品红 #c45ad0，边框 #e8d8f0。
- main 最大 36rem。标题 Georgia/宋体衬线、斜体、字重 400；主标题约 2.05rem。正文约 .95rem、行高 1.8。
- 头部用细紫金渐变线和宽字距眉题；章节卡顶部用紫/品红渐变丝带，正文保持白底；花饰“— ◆ —”独立居中。
- 阴影宽而极淡，禁止黑底夜店紫、强霓虹和大面积品红。
## 语气与层次细则
- 每节只保留一个核心意象和一个判断，斜体用于低语或转折，不把事实写得暧昧；礼仪清单仍应具体可执行。
- 品红只触碰关键处，花饰负责停顿而非填空；浅底必须保持足够文字对比，不能为了柔美而发灰难读。

## 配图与图片生成
- 统一为浅紫白丝绒品牌广告或高级静物摄影：丝绸褶皱、透明玻璃、细金属线、珍珠光泽、窗边柔光和克制景深，保持白/浅紫空间。
- 提示词必须写明人物侧影或手部、沙龙/丝绒台面场景、正在递出/收起/锁住的具体动作、物件关系、镜头、材质和柔光方向，不能只写“神秘诱惑”。
- 多张图按“美好邀约 → 看见代价或牵连 → 有礼貌地设下边界”展开，共享丝绒、玻璃、紫色色温和人物手部特征。
- 封面以单一静物或克制侧影为中心，正文用丝带、锁扣、玻璃罩等动作细节；不生成无法解释的香水瓶堆或纯背景纹理。
- 禁止情色化姿势、暴露身体、黑底夜店霓虹、图中文字、logo、二维码、水印和虚构奢侈品牌；吸引力来自材质与距离。
- 只使用素材工具返回的 `publicUrl`，不得外链、base64、临时 URL 或占位图；alt 描述人物/物件动作与材质。

## 交付校验
- 浅紫白底、衬线斜体、丝带和双线框层次清楚，品红面积克制；配图表达邀约与边界，不靠情色暗示。

真正的吸引力来自克制，不来自用力过猛。
