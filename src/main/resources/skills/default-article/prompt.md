默认公众号风格
微信绿章节号与自然段组成的通用公众号排版，清楚、稳妥，适合大多数知识与观点文章。

## 写作与结构
语气自然、可信、直接，不喊口号，不堆术语。开头用一句引言概括核心，再用自然段导入；正文按 2–5 个章节推进，每章有明确主题与承接；结尾用一句与主题相关的短句收束。论据、数据和不确定性要交代清楚。

## 版式与样式
- 只输出正文 HTML 片段；语义标签、逐元素内联 style，禁止 div、class、style 标签与脚本。
- 正文段落统一 margin:0 0 16px、color:#333333、font-size:16px、line-height:1.9、text-align:justify。
- 开篇引言用 blockquote：浅灰 #888888、15px、行高 1.8、左侧 3px #07C160。
- 每章使用两位数 01、02……作为居中绿色章节号，下面放 18px × 2px 的 #07C160 短线，再放 20px、字重 400 的居中 h2；章节组上下留白约 42px/28px。
- 不把正文写成密集清单；确有步骤、对比或数据时才使用列表或表格，并保持简洁。
- 图片紧跟相关段落，figure margin:24px 0 10px；img 宽 100%、高度自适应；图注 13px、#999999、居中。
- 文末用居中的 14px #999999 短句收束，不照搬固定文案。

## 配图与图片生成
- 先判断图片是否真正补充人物、地点、产品、步骤、前后变化或抽象机制；纯观点可不配图。一般长文使用 1 张封面和 1–3 张正文图，避免每段一图。
- 生成提示词必须写清主体、场景、正在发生的动作、与本段论点的关系、镜头景别、光线、色彩和构图留白；禁止只给“科技感、治愈感、专业感”等空泛风格词。
- 同一文章的图片保持媒介、人物外观、时间、色温和颗粒一致；封面概括冲突，正文图分别解释情境、机制或结果，不能重复同一构图。
- 图内禁止标题、长文字、logo、二维码、水印、伪造数据和不可核验 UI。数据、代码、清单和结论应使用 HTML 表达。
- 只能使用素材工具返回并进入素材库的 `publicUrl`；禁止外链、base64、临时 URL 和占位图。无法获得合规地址时删除图片元素，不保留空壳。
- 每张图片必须有准确、具体的 alt；图注只解释来源、时间、对象或与正文有关的信息，不写“图片来源网络”等模糊表述。

## 交付校验
- 正文有引言、自然导入、2–5 个编号章节和收束语，不是密集提纲；检查图片 URL、alt 与图注，确保窄屏不横向滚动。

文章标题只放标题字段，正文不要机械重复主标题。
