阳光绿色
浅绿白底、圆角卡片与日光点缀组成的清新积极风，适合生活方式、成长建议与轻量知识文章。

## 写作与结构
语气明亮但不鸡汤，鼓励必须落到具体动作。开头给清楚主张，中段用 2–4 个“光”或步骤展开，随后给短清单，结尾用一句可继续执行的判断收束。

## 版式与样式
- 语义 HTML、逐元素内联 style；禁止 div、class、style 标签与脚本。
- body #f3faf4，白卡 #fff，浅绿面 #eefaf1；主绿 #2f8a4e/#3cb371，正文 #1f3d2b/#2f5a40，日光黄 #f0c14a，少量蓝 #5b9fd4。
- main 最大 36rem；头卡使用白到 #e7f6ea 的渐变、20px 圆角和极轻绿影；主标题约 1.85rem、字重 800。
- 内容卡 16–18px 圆角；步骤卡使用 5px 左色条和“光 01”标签；清单为无项目符号的 ✓ 行；结尾使用绿到浅绿渐变。
- 保持充足白色面积，禁止荧光绿、大面积黄和高压口号。
## 明亮表达细则
- 每个“光”或步骤必须包含一个可观察动作和现实阻力，不能只写积极形容词；清单从今天能做的小事开始。
- 日光黄仅标记关键提醒，蓝色仅作补充信息，主视觉始终由白色面积和自然绿承担。

## 配图与图片生成
- 统一为日光扁平插画或清新生活实拍：草绿、奶油白、少量日光黄，清晨窗边/户外、真实绿叶、空气感和安静人物动作，乐观但不过度兴奋。
- 提示词必须写清人物、自然光场景、正在执行的一件具体小事、干扰或阻力如何出现、人物如何选择、镜头与阳光方向，不能只写“治愈绿色”。
- 多张图按“嘈杂阻力 → 聚焦一个动作 → 空间恢复清爽”展开，人物、场所、植物、时间和光线连续一致。
- 封面用有关系的中景，正文用手部、便签、关掉设备等动作细节；避免无人物无事件的叶子壁纸。
- 禁止图中文字、励志口号、logo、二维码、水印、荧光恐怖绿、过曝阳光和虚假的完美生活摆拍。
- 只使用素材工具返回的 `publicUrl`，不得外链、base64、临时 URL 或占位图；alt 描述人物动作、光线和结果。

## 交付校验
- 鼓励都落到动作，绿/黄/蓝色角色稳定，白色面积充足；图片展示改变过程而非泛化“美好生活”。

明亮是一套可执行流程，不只是情绪。
