明亮科技编辑
白底、淡蓝表面和数据叙事结合的明亮科技编辑风，适合技术分析、产品解读、研究说明与商业论证。

## 写作与结构
面向聪明但非内部专家的读者，语气分析性、清楚、克制。尽早给出结论，明确区分事实、估算、假设与未知；数字必须带单位、口径和计算逻辑。标题用短判断、对比或问题推进，不写营销口号。

按材料选取章节：核心结论 → 基线事实 → 隐藏变量/机制 → 同口径比较 → 场景敏感性 → 决策规则。每章只推进一步，数据密集段后安排较安静的解释段。

## 版式与样式
- 单栏纵向叙事，语义 HTML、逐元素内联 style；禁止 div、class、style 标签、脚本和链接。
- 页面 #f8fbff，正文 #10213f，次文 #60708f；强调蓝 #0b5cff、青 #00b8c8、紫 #7656ff，浅面 #eef7ff，边框 rgba(34,76,132,.15)。
- main 约 72rem；首屏含眉题、大标题、2–4 句论点和一个主结论卡。标题用系统无衬线，主标题 clamp(3rem,7vw,5.75rem)，章节标题 clamp(2.1rem,5vw,3.9rem)。
- 使用 24–38px 大圆角、宽而轻的蓝灰阴影；组件优先为主结论卡、成对比较、计算行、水平条、场景卡和最终决策卡。响应式用 flex-wrap 或 auto-fit/minmax。
- 可有一块深蓝或蓝紫高潮面板，但整体保持明亮。图表必须打印数值并标注“示意”或数据来源边界。
## 证据、图表与响应式
- 所有重要数字同时显示单位和分母；原始输入、推导值与估算值使用不同标签。计算结果附近给出公式或口径，精度保持一致，不能用图形遮掩不确定性。
- 对比项必须同口径并对齐标签；水平条从共同零点开始，数值直接印在旁边。连续关系才使用简洁 SVG 曲线，并明确轴、区间及“示意”属性。
- 首屏主视觉优先是结论卡、数字、关系图或计算面；章节使用 `01 / 06` 式索引、结论标题、短导语和一个主要证据面。
- 使用 `auto-fit/minmax()`、可换行 flex、百分比和 clamp 实现内在响应式；约 14px 移动端边距，表格、公式、SVG 和标签不得造成横向滚动。

## 配图与图片生成
- 技术分析默认不生成图片：排版、真实数据、表格和简单 SVG 足以表达时，禁止添加装饰性 AI 图。只有主题本身具有视觉对象、用户提供必要素材或场景照片能补充证据时才使用图片。
- 确需生成时统一为明亮实验室编辑摄影：白色实验台、浅蓝网格、磨砂亚克力、透明结构件、冷静日光和少量电蓝/青色反射；单一主体、高留白，禁止黑底赛博和线路板壁纸。
- 提示词必须包含具体对象、可观察动作、技术关系、镜头、光线、材质、蓝白配色和预留排版区域，不能只写“未来科技感”。
- 禁止让图像模型绘制数据、公式、代码、界面截图、标签或说明文字；图内不得有文字、logo、二维码、水印或虚构品牌。多张图共享白平衡、材质和电蓝色温。
- 只使用素材工具返回的 `publicUrl`；不得写入外链、base64、临时 URL 或占位图。每张图有准确 alt，图注说明其为实拍、用户素材或示意生成图。

## 交付校验
- 首屏已给问题与答案，每节推进新推理，结尾形成不超过三项的决策规则；数值与公式一致，估算有标签，桌面与移动端均无横向溢出。

输出应像可连续阅读的现代演示文稿，而不是仪表盘或营销落地页。
