清纯粉色
粉白奶油底、异形圆角与贴纸硬影组成的可爱手账风，适合轻松生活、女性向与温柔科普内容。

## 写作与结构
语气亲切、轻盈、具体；可以用少量拟声、爱心和括号表情，但不能幼稚化读者。先给温柔主句，再用 2–4 个小步骤解释，最后以柔和但明确的判断收束。

## 版式与样式
- 语义 HTML、逐元素内联 style；禁止 div、class、style 标签与脚本。
- body #fff2f6，白卡 #fff，正文 #5c3044，主粉 #c73e6a/#e2557a，边框 #ffb7d5，硬影 #ffe6f0。
- main 最大 35rem；主标题 1.75rem、字重 800。头卡使用 26–36px 不对称圆角、3px 粉边和双层柔影。
- 复用样张组件：WASHI 胶带题、胶囊气泡句、三张微倾斜糖果卡、彩色勾选框、异形收束卡。微倾斜控制在 ±0.6deg。
- 可用杏 #ffc27a 和浅紫 #c9a0e8 点缀；符号只作路标，不刷屏。
## 可爱表达细则
- 可爱来自圆润形状、比例、倾斜和留白，不靠连续撒娇；每张卡仍要有明确标题、解释和动作建议。
- 符号、爱心和星星只作路标，同类卡使用同一轮廓和影子；杏色表示温暖提示，浅紫表示补充，不随意换色。

## 配图与图片生成
- 统一为 kawaii 手账贴纸或四格可爱漫画：粉白奶油配色、粗圆描边、2–3 头身、圆润物体、简单高光和白色贴纸边，可加入胶带、曲别针等手账小物。
- 提示词必须写清圆脸角色外观、粉色书桌/生活场景、正在执行的具体动作、调皮问题如何靠近、角色如何回应、关键道具与情绪符号，不能只写“可爱女孩”。
- 多张图按“问题看起来无害 → 它制造具体麻烦 → 主角温和而明确地处理”组织，角色、服装、线条、粉色色温和贴纸白边保持一致。
- 封面用关系清楚的中景并预留标题区域，正文可用手部/道具特写；画中文字、对白和步骤由 HTML 气泡承担。
- 禁止图中文字、logo、二维码、水印、写实惊悚、成人化性感、婴幼儿化读者和只有装饰没有动作的贴纸堆。
- 只使用素材工具返回的 `publicUrl`，不得外链、base64、临时 URL 或占位图；alt 描述角色动作、道具和结果。

## 交付校验
- 异形圆角、胶带、贴纸影和符号形成统一体系但不过量；图片可爱而不幼稚，文字结论仍具体可信。

可爱来自形状与节奏，论点仍要站得住。
