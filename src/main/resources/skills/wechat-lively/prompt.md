公众号活泼
微信绿、白色圆角卡片与清晰行动项组成的轻快公众号风，适合实用知识、方法分享和大众科普。

## 写作与结构
语气清楚、亲切、有节奏，不绕弯也不卖弄。开头说明读者能获得什么；正文用问题解释、2–4 个方法和一个行动结论推进。短段为主，每个小标题直接表达收益或判断。

## 版式与样式
- 语义 HTML、逐元素内联 style；禁止 div、class、style 标签与脚本。
- body #f7f8fa，白卡 #fff，主字 #191919/#333，辅助 #888，微信绿 #07c160；少量橙 #f5a623 和蓝 #4a7dff 只用于区分步骤。
- main 最大 36rem；卡片 16px 圆角、padding 1.5–2rem、阴影 0 2px 12px rgba(0,0,0,.04)。
- 头卡含绿色胶囊眉题、1.75rem 主标题、摘要和阅读信息；正文解释卡后放三张左色条方法卡；结尾用微信绿渐变结论卡。
- 正文约 1rem、行高 1.75；每段可有 1–2 个绿色 strong，避免整段着色。
## 信息与行动细则
- 开头明确读者问题和收获，方法卡每张包含“做什么、为什么、做到什么算完成”；结论卡只保留最重要的一步。
- 绿色 strong 只标记关键词，橙/蓝步骤色前后一致；不要用卡片数量代替内容结构，也不要把每个自然段都装进卡片。

## 配图与图片生成
- 统一为明亮现代扁平插画或自然实拍：白底、微信绿/薄荷绿点缀、圆润图形、均匀自然光和充足留白，人物亲切但不过度卡通。
- 提示词必须写清主角、办公/家庭/公共场景、正在实践的具体方法、旁边的问题状态、动作产生的变化、镜头和绿色点缀位置，不能只写“公众号配图”。
- 多张图按“问题堆叠 → 执行一个方法 → 环境与结果变清楚”组织，人物、场所、媒介、光线和绿色锚点一致。
- 封面用一眼看懂的关系场景并为标题留白，正文用步骤动作或前后对照；清单、数字和结论由 HTML 排版，不让图像模型画字。
- 禁止图中文字、口号、logo、二维码、水印、乱贴标签、阴间滤镜和无关商务握手素材。
- 只使用素材工具返回的 `publicUrl`，不得外链、base64、临时 URL 或占位图；alt 描述人物动作、问题物和结果。

## 交付校验
- 读者能快速回答“为什么、怎么做、下一步是什么”；图片是方法的场景证据，不是标题复读或通用图库装饰。

目标是让读者快速得到“我懂了，而且知道下一步”。
