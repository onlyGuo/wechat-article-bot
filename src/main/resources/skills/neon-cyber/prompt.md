赛博霓虹
深紫黑底、青粉状态灯与夜间协议信息组成的赛博霓虹风，适合夜间构建、故障追踪和未来科技主题。

## 写作与结构
语气紧凑、警觉、像夜班日志；技术状态词用于标记，中文正文仍要清楚。按“signal/时间 → telemetry → 信号来源 → 三条 protocol → scan 自检 → build summary”推进。霓虹色必须有语义：绿=通过，粉=干扰，青=观测，紫=上下文。

## 版式与样式
- 语义 HTML、逐元素内联 style；禁止 div、class、style 标签与脚本。
- body #05010a；面板 #0a0418/#12002b；正文 #d4c8f0，弱文 #8a7ab0；青 #00f0ff、粉 #ff2bd6、绿 #39ff14、紫 #7c5cff。
- main 最大 38rem；状态用 Courier New，标题正文可用系统无衬线。边框 1px，glow 控制在 10–20px、透明度约 .15–.25。
- 头卡用深紫黑渐变和有限 text-shadow；telemetry 用等宽键值行；三张协议卡分别使用绿、粉、紫细边；自检使用 [OK]/[!!]/[—]。
- 禁止矩阵雨、满屏光晕和无法阅读的低对比文字。
## 信号与协议细则
- telemetry 只展示与结论有关的 3–6 个读数，注明时间、单位和状态；protocol 卡分别给动作、原因与验证，不用霓虹色替代解释。
- 故障词和英文标签保持短小，正文仍用自然中文；同一种状态始终使用同一种颜色，不能为好看随意换色。

## 配图与图片生成
- 统一为赛博朋克叙事插画/雨夜概念摄影：深紫城市或设备空间、湿地反光、单一主体、青色观测光和粉色干扰光，绿光只表示验证通过。
- 提示词必须写清角色、夜间场景、正在排查/封堵/接线的动作、异常信号从哪里进入、角色是否察觉、镜头、雨雾与各颜色的状态含义。
- 连续图按“全绿假畅通 → 粉色异常线进入 → 端口封堵后仅留验证绿”展开，角色、地点、设备和霓虹色语义一致。
- 构图保留暗部和单一视觉焦点，光晕只沿设备或人物轮廓出现；禁止满屏灯牌、矩阵雨、随机电路纹和无法阅读的过曝霓虹。
- 禁止图中文字、状态码、可读 UI、logo、二维码和水印；抽象信号可以用线、光点和管道表达，不伪造数据。
- 图片只能使用素材工具返回的 `publicUrl`，不得外链、base64、临时 URL 或占位图；alt 描述人物动作、异常信号和结果。

## 交付校验
- 绿/粉/青/紫的含义前后一致，信息层级在关闭 glow 后仍清楚；图片讲偷接、发现或封堵故事，不是霓虹壁纸。

页面可以亮，信息必须静。
