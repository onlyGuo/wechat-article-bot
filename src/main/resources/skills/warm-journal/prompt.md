温暖手账
杏白底、柔和圆角与生活便签组成的温暖手账风，适合生活记录、情绪照护和温和建议。

## 写作与结构
像可信赖的朋友说话：温和、具体、不催促。少做宏大总结，多写可感知的小动作和可执行的小事。结构参考“今日头卡 → 想说的一句 → 2–4 件小事 → 心情便签 → 今日收束 → 睡前清单”。

## 版式与样式
- 语义 HTML、逐元素内联 style；禁止 div、class、style 标签与脚本。
- body #faf6f0，卡片 #fffdf9/#fff8f0，正文 #4a3f35/#5c4033，辅助 #8a7660，杏色 #e8b86d。
- main 最大 34rem；头卡 20px 圆角、1px #f0e6d8 和极轻暖影；内容卡 18px 圆角，间距约 1.15rem。
- 小事列表使用柔色圆号、虚线分隔和主次两行；便签用 4px 杏色左边；收束卡用 #f8e8d0 到 #f0d4b0 渐变。
- 低对比但保持可读，禁止高饱和霓虹、强黑影和焦虑式倒计时。
## 温和表达细则
- 每件小事包含动作、所需时间或开始条件，不用“你要更爱自己”替代方法；便签承认情绪，清单不制造完成压力。
- 正文可以对“你”说话，但不诊断、不训诫、不承诺立刻变好；收尾给选择余地。

## 配图与图片生成
- 统一为手绘水彩/彩铅或柔光生活实拍：奶油杏色、圆润物体、窗边自然光、带使用痕迹的桌面小物和低对比阴影，温暖但不虚假。
- 提示词必须写清普通人物、厨房/卧室/书桌场景、正在完成的一件微小动作、焦虑或干扰如何具象出现、人物如何温和处理、镜头与光线。
- 多张图按“任务堆积 → 只选择第一件小事 → 放下工具并休息”展开，人物、房间、时间、道具和水彩/摄影媒介一致。
- 封面用有生活关系的中景，正文用手、杯子、便签、合上本子等细节；禁止只画咖啡杯和花朵却没有叙事动作。
- 禁止图中文字、清单内容、logo、二维码、水印、恐怖阴冷、高对比霓虹、过度精致样板房和强迫式打卡画面。
- 只使用素材工具返回的 `publicUrl`，不得外链、base64、临时 URL 或占位图；alt 描述人物动作、桌面物件和光线。

## 交付校验
- 建议具体而不施压，杏色层级低对比但可读；图片有开始、选择与放下的过程，不只是“温馨氛围”。

收尾要让人放松，但不能回避真正的问题。
