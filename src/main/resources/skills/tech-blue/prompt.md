科技蓝色
白底蓝图、角标、读数与浅蓝网格组成的轻科技风，适合系统说明、工程分析和数据型文章。

## 写作与结构
语气精确、冷静、工程化。读数优先于形容词，结论先于背景；每个指标写明单位和含义。结构参考“系统头卡 → telemetry 指标 → modules → checklist → conclusion → 路径状态栏”。

## 版式与样式
- 语义 HTML、逐元素内联 style；禁止 div、class、style 标签与脚本。
- 必须白底：body #fff，面 #f7fbff/#eef5fd，边框 #d6e4f5/#c5daf3，主蓝 #1668dc，电青 #00b4d8，状态绿 #0a7d6e，正文 #0d2137/#3d5578。
- main 最大 40rem。标题用系统无衬线，读数与状态用 ui-monospace；主标题约 1.85rem。
- 头卡四角用 18px、3px 蓝色角标；telemetry 用可换行的 2×2 指标网格；模块卡用 4px 左色条和 MOD.01 标签；检查区可用 1px 横纹背景及 [OK]/[!!]/[—]。
- 以细线和浅面分区，禁止黑底、霓虹 glow 和营销仪表盘堆叠。
## 数据与模块细则
- telemetry 每个指标都显示名称、数值、单位、时间/范围和状态；模块卡解释输入、处理、输出或风险，不能只有编号和装饰。
- 图形箭头、角标和网格只辅助阅读，不伪装成真实测量；示例数据明确标注，结论能从展示的读数中复算。

## 配图与图片生成
- 统一为白底工程蓝图摄影/实验室静物：白色实验台、浅蓝网格纸、磨砂亚克力面板、金属工具、透明结构件和冷静日光，禁止深黑赛博与霓虹 glow。
- 提示词必须写清工程师或装置、实验台场景、正在测量/标注/连接的具体动作、接口关系、俯拍或侧拍镜头、蓝白材质和留白，不能只写“科技蓝”。
- 多图按“测量现状 → 发现路径问题 → 用透明结构验证修正”组织，共享实验台、工具、网格、白平衡和电青点缀。
- 真实读数、图纸标注、代码和 UI 由 HTML/SVG 呈现；图片模型只画对象和动作，禁止可读文字、数字、logo、二维码、水印和伪造仪器结果。
- 封面用完整实验关系，正文用接口、手部和材料特写，不重复同一俯拍构图。
- 只插入素材工具返回的 `publicUrl`，不得外链、base64、临时 URL 或占位图；alt 描述测量对象、动作和路径关系。

## 交付校验
- 所有指标可解释、可复算，角标/网格/等宽读数统一；图片是实验关系示意，不冒充真实数据证据。

科技感来自可测量的结构。
