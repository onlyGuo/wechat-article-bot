暗色失落
近黑留白、故障状态与逐渐消退文字构成的暗色情绪风，适合失败复盘、等待、耗尽和荒诞失落主题。

## 写作与结构
使用冷静的第一人称或近距离旁白。句子短，允许克制重复、停顿和空白；情绪由事实与节奏累积，不靠连续感叹号。技术状态词可穿插，但不能掩盖真实叙事。结构按“异常状态 → 反复尝试 → 失落清单 → 回声衰减 → 最终残句”推进。

## 版式与样式
- 只输出语义 HTML 和逐元素内联 style，禁止 div、class、style 标签与脚本。
- body #080808，main 最大 44rem，垂直留白用 8–12vh；正文 Georgia/宋体，状态 Courier New。
- 主文 #8a8a8a，亮句 #c8c8c8/#e0e0e0，弱句按 #6a6a6a → #3a3a3a → #1c1c1c 衰减。
- 主标题用 clamp(2.8rem,10vw,4.5rem)，字重 400；状态眉题约 .7–.85rem、宽字距。面板 #0c0c0c、1px #1f1f1f，可轻微 rotate ±0.4deg。
- 复用样张组件：STATUS 键值行、ERR_* 片段、短句大字组、失败清单、同句逐层变暗的回声、final dump。避免彩色霓虹和密集卡片。
## 配图与图片生成
- 配图只用于关键情绪转折或展示“人正在做无意义的重复动作”，不能用黑底口号图复读正文。通常封面一张、转折处一张即可，宁缺毋滥。
- 统一画风为低饱和灰黑概念摄影/惊悚氛围图：废弃机房、空大厅、熄灭屏幕或黑暗工位，单侧冷光或极少惨绿应急灯，浅景深、胶片颗粒、灰尘和大面积黑场。
- 提示词必须包含人物或拟人事物、空旷场景、正在重复的具体动作、没有回应的对象、人物是否察觉、镜头距离与唯一光源，不能只写“空洞、疯狂、绝望”。
- 用灯不亮、线缆被拔、按钮反复按下、椅子空着等物体状态表达失落；不要生成可读错误码、状态字样或文章标题。
- 连续图按“假平静 → 重复尝试 → 空结果”形成分镜，并共享场景、角色、惨淡色温和颗粒；单图选择最能显示动作与空旷尺度的中远景。
- 禁止文字、logo、二维码、水印、彩虹霓虹、血腥猎奇和突然的阳光希望感。只使用素材工具返回的 `publicUrl`，不得外链、base64、临时地址或占位图；alt 客观描述场景。

## 交付校验
- 回声文字逐层衰减，状态面板可读，黑位仍有足够对比；图片讲述动作与结果，不把标题画进图里。

结尾应留下余震，不要突然励志或给出廉价安慰。
