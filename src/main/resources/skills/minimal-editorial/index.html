Essay · No. 04 · Minimal Editorial

少即是准确

极简杂志风不是把字变少，而是让每一个留下的字都站得住。

样张 · 约 3 分钟 · 无 div / 无 JS / 无 class

I · 开篇

页面一空，人就容易慌：是不是写得太少？是不是不够「设计感」？于是标题加粗、底色叠块、形容词堆叠——信息没有变多，噪音变多了。

编辑风的克制，不是冷淡，是替读者做选择：删掉不能推进阅读的句子，留下能被记住的结构。

Pull quote

留白不是没写完，是把注意力写进版面。

II · 三条版面原则

01

一栏一心智

每屏只服务一个阅读任务。小标题是路标，不是装饰。

02

字号阶梯固定

大标题、引语、正文、注释，四级够用。再加一档，层次就会塌。

03

强调只用一次

加粗、引语、色线，一页最多各出现一次。重复强调等于没有强调。

版面备忘

  • 正文行宽控制在 34–38 个汉字
  • 段间距大于行距，但不要超过两倍
  • 颜色不是内容；去掉色后仍站得住，才算排完

III · 收束

极简杂志风的完成标准很简单：远看有结构，近看有句子，抽掉装饰后依然成立。

下一次排版时，先问：如果只准留三分之一，留什么？
