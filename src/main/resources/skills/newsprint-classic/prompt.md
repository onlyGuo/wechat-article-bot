复古报纸
米黄纸、双线报头与社论版块组成的复古新闻纸风，适合行业观察、事件解读和鲜明评论。

## 写作与结构
采用新闻编辑语气：导语先交代发生了什么、为何重要，再展开证据与判断。标题应可独立转发；事实与评论分开，引用和数据注明来源边界。结构参考“报头 → 头条与简讯 → 三条要闻 → 社论 → 读者清单 → 全文完”。

## 版式与样式
- 语义 HTML、逐元素内联 style；禁止 div、class、style 标签与脚本。
- body #f7f3ea，纸面 #fbf8f1，文字 #111/#222，线 #cfc7b8，暗红 #8b0000 只用于栏目眉题。
- main 最大 40rem，左右 1px 纸边；标题和正文以 Times New Roman/宋体为主，辅助标签用系统无衬线。报头主标题约 2.2rem，底部 3px double。
- 宽屏可用 flex 做头条/简讯双栏，窄屏必须自然换行；社论框用 2px 黑边和 #f0eadc，其他块用细线而非阴影。
- 段落短，列表像读者服务栏；避免网页卡片、圆角按钮和发光 UI。
## 新闻表达细则
- 导语回答发生了什么、影响谁、为何现在重要；要闻段落给事实和出处边界，社论框再给立场，二者不能混写。
- 日期、地点、人物身份、数字和引语不得编造；不稳定事实需核验。栏目标题可有报纸腔，正文保持现代可读中文。

## 配图与图片生成
- 优先使用真实来源明确的新闻照片或用户素材；只有没有合适素材且图片用于示意时才生成，并在图注标明“示意图”。不能生成图片冒充新闻现场证据。
- 统一视觉为复古新闻摄影、铜版画或半色调插画：米黄纸色、黑白/棕褐颗粒、纪实中景、自然动作和头版照片式构图，避免现代发光 UI。
- 生成提示词必须写明人物身份、地点、正在发生的公共动作、可见证据物件、镜头距离、时代中性的服装与报纸颗粒；不能只写“复古报纸风”。
- 多图保持相同纸色、半色调密度和裁切比例；封面建立现场，正文图补充人物动作或证据细节，不能把社论观点伪装成现场。
- 禁止图内报纸标题、可读标语、logo、二维码、水印、虚构媒体标识、真实人物换脸和可能被误认为事实的伪造事件画面。
- 只使用素材工具返回的 `publicUrl`，不得外链、base64、临时 URL 或占位图；alt 客观描述画面，图注写明时间、地点、来源或“AI 生成示意图”。

## 交付校验
- 事实与评论分区明确，标题可独立成立，双栏在窄屏按阅读顺序堆叠；图片来源属性不会误导读者。

结尾应落下明确判断，不写空泛感想。
