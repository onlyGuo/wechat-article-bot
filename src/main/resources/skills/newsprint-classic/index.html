头条

编辑部主张：句子砍半，信息不丢

长文不等于认真。报纸的规矩很简单：导语交代五要素，正文只保留能被引用的句子。

把话说短，是版面伦理，也是对读者时间的尊重。

简讯

本市多部门推行「一页纸说明」，附件无限加。

调查显示：读者平均只读完导语与小标题。

评论：能删的形容词，都是噪音。

排版要闻 · 三条

一、导语不绕

谁、什么、为何重要——三句内说完，不靠悬念吊人。

二、标题可独立转发

标题离开正文仍成立；不成立，就不是报纸标题。

三、结论要落在纸上

文末给出可执行动作或明确判断，不写空泛感想。

社论

短，是一种负责

报纸版面有限，所以必须取舍。网页无限滚动，取舍反而更难——难在克制，不难在排版。

把话说短：导语清晰、要点分明、结尾落刀。

读者服务 · 今日清单

  • 删掉一句可有可无的形容词
  • 给每个小标题补上判断
  • 文末写清「下一步做什么」
