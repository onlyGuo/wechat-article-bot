苹果桌面窗口
深色桌面、白色圆角窗口与系统列表组成的苹果桌面窗口风，适合工具介绍、清单和轻量产品说明。

## 写作与结构
语气简洁、友好、克制，像系统设置说明：先说作用，再给选项和结果。避免营销夸张、连续口号和技术炫耀。结构参考“主窗口标题 → 设置列表 → 设计/使用要点 → 分段控件式比较 → 结论”。

## 版式与样式
- 语义 HTML、逐元素内联 style；禁止 div、class、style 标签与脚本。
- body 使用 #1c1c1e 至 #3a3a3c 的深灰渐变桌面；main 最大 40rem。内容窗口 #fff，次面 #f5f5f7，边框 #e5e5ea。
- 字体用系统 sans；标题 #1d1d1f，正文 #3a3a3c，辅助 #8e8e93。窗口 12px 圆角，控件 7–9px；窗口阴影 0 12px 40px rgba(0,0,0,.28)。
- 标题窗顶部放红 #ff5f57、黄 #febc2e、绿 #28c840 三个小圆点。列表行为图标块 + 主次文字 + ›，用极浅分割线。
- 系统蓝 #007aff、绿 #34c759、紫 #af52de 只作小面积图标或选中态，禁止按钮墙。
## 窗口与控件细则
- 窗口只模拟视觉语法，不伪装成可点击应用；设置行必须有主标题、次说明和明确结果，箭头仅表示进入下一层信息。
- 同一列表中的图标尺寸、底色和行高一致，分段控件最多 2–4 项；结论窗口比设置窗口更安静，避免层层套窗。

## 配图与图片生成
- 只有硬件场景、桌面使用动作或权限关系确实有助理解时才配图；系统设置内容用 HTML 列表表达，不让图像模型生成可读 UI。
- 统一为苹果广告式产品摄影/界面概念图：浅色桌面、金属与磨砂玻璃、柔和窗光、红黄绿小圆点和大量留白；质感干净但不复制任何品牌界面。
- 提示词必须写清使用者、设备、正在关闭/移出/确认的具体动作、对象所在位置、镜头角度、柔光与留白区域，不能只写“苹果风”。
- 连续图按“对象仍被允许 → 用户执行拖出/关闭 → 状态干净确认”组织，并保持同一设备、桌面、手部和光线。
- 禁止品牌 logo、可读菜单文字、伪造系统截图、产品商标、二维码、水印、杂乱赛博背景和过度玻璃特效。
- 只使用素材工具返回的 `publicUrl`，不得外链、base64、临时 URL 或占位图；alt 描述设备、手部动作和结果，不写品牌猜测。

## 交付校验
- 白窗、深桌、交通灯和列表层级统一，所有窗口在手机宽度自然收缩；配图展示真实动作，不承担设置项文字。

整体要像一个可读的系统窗口，不是仿真的可交互应用。
