高级黑金：贵在收敛

黑是场，金是光。约束：无 div / 无 JS / 无 class / 全内联。克制，才是高级。

Principe

金线不包边，只切开

黑金页禁止大块金底。金色只作 1–2px 线、小号衬线标题、细分割，像礼盒上的烫金压痕。

再亮的金，摊开就不贵了。

三段式礼仪

CHAPITRE I or fin

开场：压暗环境

近黑底 + 金标题 + 大留白，先把噪音关掉。

CHAPITRE II palais

中段：细线分区

卡片用深灰面 + 1px 金描边；小标题金、正文灰米，层级冷静。

CHAPITRE III scellé

收束：一枚印记

结尾一句判断 + 细金线徽章，不堆口号。

MATIÈRES
  • ◆衬线标题 + 无衬线正文
  • ◆金色饱和度低于荧光黄
  • ◆禁止金底铺满、禁止霓虹描边
