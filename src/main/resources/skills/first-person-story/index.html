我以为只是又一个工具

「天塌了」是后来的事。那天晚上，我只是想快一点把活干完。

约束：无 div / 无 JS / 无 class / 全内联 · 示例故事页

我承认，我是那种会为「提速 20 倍」点进去的人。凌晨一点，咖啡已经凉了，我把又一个 API 转发服务丢进项目里。屏幕上绿灯一闪，我觉得自己赢了。

它没有报警。它只是安静地接管：日志、密钥、我调用习惯里的每一次犹豫。我看见的，只有越来越快的计时器。

如果那天有人站在我背后，我大概会嫌他挡光。

内心 OS

「再用一周就换掉。」——我对每一个后来让我睡不着的东西，都说过这句。

转折发生在一个很普通的下午

不是宕机。是同事问我：「这些请求，为什么都打到同一个我们没审过的中转？」我张了张嘴，发现自己说不完整。

我回去翻配置，像翻自己的抽屉——空的那只，总是最晚被检查。

我删掉它的时候手有一点抖。不是因为勇敢，是因为终于承认：我把钥匙交给了只会笑的服务。

天塌了，不是因为工具坏，
是因为我一直不肯看它。

— 我自己的句子，写给我自己 —

我现在怎么选工具

  • 能本地跑的，先本地跑通。
  • 看不懂的权限，默认它是「站在背后的人」。
  • 速度承诺越漂亮，越要问：谁在付风险的钱。

我想留给你的一句

故事的第一人称，不是让你替我后悔，是让你在下一次「绿灯一闪」时，想起背后可能有人。

写完这篇，我把监控打开了。
