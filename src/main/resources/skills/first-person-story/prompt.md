第一人称故事
纸张色、宋体长文与私人手记节奏的第一人称叙事风，适合亲历、反思、成长与案例复盘。

## 写作与结构
始终从“我”看到、做过、误判和改变的具体经历出发。语气诚实、克制、有自嘲但不卖惨；用时间、动作、物件和对话呈现场景，少做上帝视角总结。按“当时的选择 → 未察觉的代价 → 普通时刻里的转折 → 承认与行动 → 留给读者的一句”推进。

## 版式与样式
- 语义 HTML、逐元素内联 style；禁止 div、class、style 标签与脚本。
- body 纸色 #f4efe6、文字 #2c241c；main 最大 34rem，padding 2.5rem 1.25rem 4.25rem。
- 正文和标题以 Georgia、宋体为主，正文约 1.05rem、行高 1.9；主标题 1.85rem、#1a1410。
- 头部用细底线和小号宽字距眉题；正文以自然段为主。可穿插一块 #ebe4d6、左边 3px #8b6914 的“内心 OS”卡。
- 中段安排一条居中、1.35rem 的自我判断句；结尾可有三点经验和一块白底留句卡，但不要把故事改成教程。
## 场景与叙事细则
- 每个转折至少包含时间或地点、一个可见动作、一个感官细节和当时的误判；重要结论从事件中长出来，不用事后全知视角替角色辩解。
- 对话只保留真正改变局面的句子；内心 OS 卡写当时所想，居中判断句写现在才明白的事，两者不得重复。

## 配图与图片生成
- 配图采用电影剧照、纪实摄影或日记附图，优先第一人称 POV、过肩镜头、手部特写与真实工位/居所中景。色调为暖褐纸感、低饱和自然光或台灯光，关键冲突帧可稍冷。
- 提示词必须写出叙述者所处时间地点、正在做的动作、画框边缘同时发生但当时未察觉的细节、镜头视角、光源和 35mm 胶片质感，不能只写“一个人的成长故事”。
- 桌面物件、衣着和环境应真实使用过而非摆拍；屏幕内容虚化，不生成可读聊天、代码或品牌界面。人物表情克制，动作比正脸更重要。
- 多张图按“选择/进入 → 裂缝被看见 → 做出改变”组成分镜，人物外观、场所、时间线和胶片色彩连续。
- 禁止画中口号、标题、logo、二维码、水印、表情包大头贴和过度美颜。图片必须来自素材工具返回的 `publicUrl`，不得外链、base64、临时 URL 或占位图；alt 写清视角、动作与场景。

## 交付校验
- 通篇能辨认“我”在何时、何地、做了什么、如何误判并改变；仅看图序也能看出选择、裂缝和行动的变化。

读者应先相信这个人，再接受这个结论。
